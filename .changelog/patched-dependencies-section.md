- **A "Patched dependencies" section** (`README.md`, `scripts/check-patches.mjs`): each `bun patch` patch gets one line in the README with the package and version, what it fixes, the upstream issue, and when to delete it, because `package.json` cannot carry that reason. The section also holds the steps for a failing `patches` job: delete the patch when the new version has the upstream fix, otherwise patch the new version and delete the old patch file and key, which `bun patch --commit` keeps. The `patches` error message now points to the section. To apply: copy the section into your README, add a line for each patch the project already has, and copy `scripts/check-patches.mjs`.
