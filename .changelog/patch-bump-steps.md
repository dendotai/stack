- **Safe steps to move a patch to a bumped version** (`README.md`, "Patched dependencies"): bun applies a patch file by line number and checks nothing around it, so an old patch file renamed to the new version changes whatever the new version holds on those lines, without an error. The steps now copy the old change with `git apply`, which fails when any line around it changed, between `bun patch <name>@<new version>` and `bun patch --commit`. `GIT_CEILING_DIRECTORIES` keeps `git` from finding the project's repo, where `git apply` skips the file and still exits 0. To apply: copy the steps of the "Patched dependencies" section.
