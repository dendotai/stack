- **ADR `## Rejected` section** (`docs/adr/`): the template has a section
  after `Consequences` for the options examined and declined, each with the
  reason it lost, so the reason stays on record when the option is proposed
  again ([docs/adr/0000-template.md](docs/adr/0000-template.md),
  [docs/adr/README.md](docs/adr/README.md)). An ADR keeps it only when a
  declined option is likely to be proposed again. To apply: append the
  section to your `docs/adr/0000-template.md` and add it to the section list
  in `docs/adr/README.md`; existing ADRs need no change.
