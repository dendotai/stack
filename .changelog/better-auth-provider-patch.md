- **`@convex-dev/better-auth` patched in place of the `AuthClient` cast** (`patches/`, `package.json`, `apps/web/src/lib/auth-bridge.tsx`, `README.md`): [get-convex/better-auth#420](https://github.com/get-convex/better-auth/issues/420) makes the `authClient` of `ConvexBetterAuthProvider` reject what `createAuthClient` returns. The cast fixed one call site, and every new one (a mobile app's root layout) failed the type check with TS2322 again; the patch fixes the provider's type once for every call site, so `auth-bridge.tsx` passes `authClient` uncast. The patch check now also runs in `bun run check`, and a `postinstall` script runs it with `--warn` after every install, so a bump that drops a patch is reported on the machine that made it. To apply: copy `patches/@convex-dev%2Fbetter-auth@0.12.5.patch`, the `patchedDependencies` key, the `check` and `postinstall` scripts from `package.json`, and `scripts/check-patches.mjs`; run `bun install`; drop the cast at each `ConvexBetterAuthProvider` call site; add the patch's line to your README's "Patched dependencies" section.
