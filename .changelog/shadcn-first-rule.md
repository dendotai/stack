- **shadcn on its current default, and shadcn first for UI components** (`apps/web`): shadcn is re-initialised on the `base-nova` style (Base UI, `@base-ui/react`) in place of `new-york` on Radix, with the `cn` package in place of `clsx` + `tailwind-merge` (`lib/utils.ts` re-exports it), shadcn's current `styles.css` tokens and the Geist font. The login page and the sign-out button use shadcn's `Button`, `Input` and `Label` from `src/components/ui/`, which Biome formats but does not lint. A new section in `apps/web/CLAUDE.md` tells an agent to search shadcn (`bunx shadcn@latest search @shadcn -q <name>`) before building a UI component and to treat `src/components/ui/` as vendor code. To apply: in `apps/web`, run `printf 'y\n' | bunx shadcn@latest init -p nova -b base --force --no-rtl --no-monorepo --reinstall`, remove `clsx` and `tailwind-merge`, then copy the `biome.json` `overrides` entry and the `## UI components: shadcn first` section; a component outside `src/components/ui/` that imports Radix needs a manual move to Base UI.
