- **CI fails when a `bun patch` patch no longer applies** (`scripts/check-patches.mjs`, `.github/workflows/test.yml`): `bun install` skips a `patchedDependencies` entry without a warning once a version bump moves the package off the version in the entry's key, `--frozen-lockfile` included ([oven-sh/bun#40106](https://github.com/oven-sh/bun/issues/40106)). The new `patches` job in the `test` workflow runs the script, which fails and names the package, the patched version and the version `bun.lock` resolves; with no `patchedDependencies` it passes and prints nothing. To apply: copy `scripts/check-patches.mjs` and the `patches` job from `test.yml`, and add `patches` to any ruleset or branch protection that lists the required checks.
