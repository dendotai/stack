- **Offline e2e harness** (`packages/api/e2e`, `apps/web/e2e`, root `e2e` script, `.github/workflows/test.yml`): `bun run e2e` starts a local `convex-local-backend` at the version in `packages/api/e2e/CONVEX_LOCAL_BACKEND_VERSION`, deploys `convex/` to it, and tests Better Auth over HTTP, then builds the Worker, runs it under `wrangler dev`, and signs in and renders `/home` through the auth proxy. It needs no cloud deployment and no secrets; CI caches the binary. See [ADR 0009](docs/adr/0009-e2e-runs-the-convex-backend-binary.md). To apply: copy both `e2e/` folders; in `packages/api/package.json` add the `e2e` script, the `./e2e/local-backend` and `./e2e/deployment` exports, `@types/node`, and `&& tsc --noEmit -p e2e/tsconfig.json` to `typecheck`; add `exclude: ["e2e/**", "**/node_modules/**"]` to `packages/api/vitest.config.ts`; in `apps/web/package.json` add the `e2e` script and the same `typecheck` suffix; add the root `e2e` script and the `packages/api/e2e/.cache/` line to `.gitignore`; copy the `e2e` job into `.github/workflows/test.yml`. Tests for features the project has and the template lacks go next to these.
